# Reactor Control 3×5

Компактный интерфейс управления реакторами для OpenComputers / McSkill HiTech 1.12.2.
Монитор: **5 блоков в ширину × 3 в высоту**, монитор и видеокарта третьего уровня.
Рабочее разрешение — 100×30 символов. Шесть реакторов одновременно: три карточки в ряд, два ряда.

## Установка одной командой

В терминале OpenOS с интернет-картой:

```sh
wget -fq https://raw.githubusercontent.com/CptFishHead/Reactor-Control-3x5/main/install.lua /home/reactor-setup.lua && /home/reactor-setup.lua
```

Сначала остановите реакторы и выйдите из старой программы, если она уже установлена.
Установщик сам скачает программу и библиотеки, проверит синтаксис, сохранит резервные копии,
настроит автозапуск и перезагрузит компьютер. При первом запуске добавьте свой ник в настройках.
Конфигурация `/home/data/config.lua` и раскладка при обновлении сохраняются.

## Что умеет

- Управление каждым реактором и всем комплексом; аварийная блокировка запуска.
- Температура, генерация, распад топлива, заполнение буфера в процентах и расход в карточках.
- Переключатель `[⭘]` в заголовке: зелёный — работает, красный — остановлен; `[!]` — авария.
- Блок «Метрики» справа внизу: генерация, жидкость в МЭ, порог, расход и обновление МЭ.
- Время работы слева внизу. Единицы, порог и обновление МЭ доступны на вкладке «Журнал».
- Настройки пользователей, ChatBox и существующая логика автоматического отключения.
- Журнал на отдельной вкладке с прокруткой. Для 7–12 реакторов — вторая страница.
- Редактор положения и размера карточек с сохранением на диск.
- Приглушённый пиксельарт трёх реакторов на фоне, нарисованный средствами монитора.

## Как двигать и менять размер

1. Нажмите **«Раскладка»** вверху.
2. Перетащите карточку мышью. Пересечения разрешены; выбранная карточка поднимается наверх.
   Tab позволяет выбрать и поднять карточку, даже если она полностью закрыта другими.
3. Тяните **«+» в правом нижнем углу** для изменения размера либо пользуйтесь кнопками
   «Ширина −/+» и «Высота −/+». Стрелки сдвигают выбранную карточку на один символ.
4. Для названия нажмите **«Имя / F2»**, введите до 32 символов и нажмите Enter.
   Пустое имя возвращает стандартное «Реактор #N». Номер реактора сохраняется в заголовке.
5. Нажмите **«Сохранить» / Enter**. **«Отмена» / Esc** вернёт прежнюю раскладку,
   **«Сброс»** подготовит стандартную сетку; сброс также нужно сохранить.

Минимальная карточка — 24×7 символов. Карточки размещаются внутри рабочей области,
не перекрывая общие кнопки управления. Карточки могут перекрывать друг друга;
нажатия получает только верхняя карточка. Названия задаются отдельно для каждой страницы.
В редакторе показаны сетка, линейка столбцов и координаты выбранной карточки.
Сетка помогает выравнивать карточки; перемещение по-прежнему выполняется по одному символу.
Во время редактирования сбор показателей и защитные проверки продолжаются.
Кнопки запуска и остановки в редакторе скрыты; они доступны на страницах «Реакторы» и «Журнал».
Подписи кнопок выровнены по центру. Новая стандартная сетка использует карточки 31×8;
существующие позиции и названия сохраняются. Для новой сетки нажмите «Раскладка» →
«Сброс» → «Сохранить»; названия при сбросе останутся.

Подробности установки, обновления и восстановления: [INSTALL-3x5-RU.md](INSTALL-3x5-RU.md).
